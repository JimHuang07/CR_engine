# CR Review Engine

第一版以單一防守局面為單位。輸入目前四張手牌、下一張牌、聖水量，以及各防守方案的出牌順序、聖水消耗和預估掉塔血量。

```powershell
node review.mjs example.json
node --test
```

引擎逐張檢查方案。第一張打出後，已知的下一張牌才可用。每個方案必須以目前的聖水付清。空的出牌序列代表保留聖水。

分數 = 預估掉塔血量 + 100 × 使用聖水。分數越低越好，同分時保塔血優先。`example.json` 使用手填的示範數字。引擎在給定候選中排名，掉血估計、卡牌費用與候選的來源都由呼叫端提供。這版假設分析窗口內沒有聖水回復，也只使用一張已知的循環牌。

核心入口為 `rankDefenses(snapshot)`。之後可以把手填的估計替換為依落點與時機計算的短時段模擬結果。
